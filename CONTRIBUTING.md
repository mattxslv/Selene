# Contributing to Selene

Thanks for your interest in improving Selene.

Selene is maintained by one developer. I handle code changes, merges, and releases myself. Community bug reports, feature requests, feedback, and technical suggestions are welcome.

## Reporting bugs and suggesting features

- **Bugs** go to [GitHub Issues](https://github.com/mattxslv/Selene/issues). Include steps to reproduce, your Playnite and Selene versions, and screenshots or logs when useful. The quickest way is from Selene itself: press both sticks in (or Selene settings > Advanced > Report a problem).
- **Ideas and requests** go to [Discussions > Ideas](https://github.com/mattxslv/Selene/discussions/categories/ideas), where everyone can vote for the ones they want most. Explain the problem you want to solve. Selene's Report a problem screen can send an idea there too.
- **Questions** go to [Discussions > Q&A](https://github.com/mattxslv/Selene/discussions/categories/q-a).

## Code suggestions and pull requests

You can share an implementation idea or open a pull request for discussion, but **external pull requests are not merged directly**. I review suggestions and may implement an approach independently in a maintainer-owned branch after checking security, compatibility, performance, and maintainability.

Please start a discussion before spending significant time on a patch. Not every suggestion can be included.

When incorporating third-party code, I will respect applicable licenses and attribution requirements. I will credit useful community ideas where appropriate.

## Maintenance and releases

Only the maintainer decides what enters the main branch and publishes releases. Reporting an issue or opening a pull request does not grant repository write access.

Thanks for helping make Selene better.
